## 🚀 Quick Reference

| Aspect | Details |
|--------|---------|
| **Pattern** | 2-sided flip card with 3D rotation |
| **Animation** | 700ms smooth Y-axis rotation |
| **Heights** | All 320px (consistent) |
| **Layouts** | Same structure, different data |
| **Colors** | Color-coded by type (Green/Blue/Orange/Red) |
| **Icons** | Lucide React icons throughout |
| **Responsive** | 1 col (mobile) → 2 col (tablet) → 3 col (desktop) |
| **State** | `isFlipped` boolean toggle |
| **Interaction** | Click anywhere/flip button to rotate |
